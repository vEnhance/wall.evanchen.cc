I'm always reminded of this sentence in [esr's how to ask questions][ask]

> When asking your question, it is best to write as though you assume _you_ are
> doing something wrong, even if you are privately pretty sure you have found an
> actual bug. If there really is a bug, you will hear about it in the answer.
> Play it so the maintainers will want to apologize to you if the bug is real,
> rather than so that you will owe them an apology if you have messed up.

I feel like I always did this, and it just seemed like common sense to me.
In fact, I assumed that's what everyone did. But apparently not?

[ask]: http://www.catb.org/~esr/faqs/smart-questions.html
