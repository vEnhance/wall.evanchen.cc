I realized when playing [The Farmer Was Replaced](https://www.youtube.com/watch?v=xsh-ZBwg-B4)
how I've gotten used to _not_ optimizing my code in real life.

For me, the most important thing with my Python code
is that it's easy to read and obviously correct.
For my applications a runtime of 1 millisecond vs 10 milliseconds doesn't matter.
(If runtime _did_ matter, I might not be using Python anyway.)
