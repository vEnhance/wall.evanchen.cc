i still think a class along these lines should be a General Institute Requirement:

- figure out how to use a shell and install `zola` (or other SSG)
- learn survival skills in Vim (or VSCode…)
- run `zola init`, put together a website skeleton, and commit to git
- run `zola serve` and see how you can develop a static website locally
- install a pre-commit framework for at-commit-time linting
- set up an SSH key for GitHub/GitLab etc.
- buy a domain on CloudFlare
- create a GitHub pages workflow and point the new domain at it

and the student would walk away with a barebones personal website
